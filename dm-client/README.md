# dm-client

## Назначение

`dm-client` — настольное приложение мастера игры на JavaFX. Через него мастер создаёт или загружает сессию, подключается к серверу, управляет боевым состоянием и передаёт карту в player-client.

## Роль в общей архитектуре

Это рабочая панель оператора сессии. Модуль не заменяет сервер и не дублирует player-client, а связывает оба модуля:
- с одной стороны он общается с `server` по REST и WebSocket;
- с другой — координирует стартовый вход в боевой экран player-client.

## Зависимости

- Java 17
- JavaFX 21
- `shared`
- `spring-websocket`
- `spring-messaging`
- `tyrus-standalone-client`
- `okhttp`
- `jackson-databind`

Ключевые точки входа и интеграции:
- `com.avalon.dnd.dm.DmApplication`
- `com.avalon.dnd.dm.DmApp`

## Конфигурация

Поддерживаются:
- `avalon.serverUrl`
- `AVALON_SERVER_URL`
- `avalon.playerClientUrl`
- `AVALON_PLAYER_CLIENT_URL`
- `avalon.launcher.controlUrl`
- `AVALON_LAUNCHER_CONTROL_URL`

Если URL не задан, клиент пытается использовать локальные значения по умолчанию.

## Локальный запуск

```bash
./gradlew :dm-client:run
```

Если сервер уже поднят отдельно, укажи его URL через переменную окружения или системное свойство.

## Тестирование

```bash
./gradlew :dm-client:test
```

## Примеры использования

### Создать новую сессию
1. Открыть DM-клиент.
2. Указать URL сервера.
3. Нажать создание новой сессии.
4. Получить `sessionId` и `dmSecret`.
5. Подключиться и открыть battle view.

### Загрузить сохранённую сессию
1. Открыть вкладку загрузки.
2. Выбрать сохранённую сессию.
3. Нажать загрузку.
4. Подключиться к восстановленному состоянию.

### Импортировать карту
DM-клиент умеет отправлять workspace в сервер через import-map workflow.

## Особенности реализации

- Стартовый экран работает как контрольная панель подключения.
- Используется STOMP через SockJS/WebSocket.
- При подключении клиент получает `SessionStateDto` и затем подписывается на приватный канал игрока.
- Есть работа с сохранёнными сессиями и импортом карты из workspace.
- В коде присутствует защита от дублей listener'ов при переподключениях.
- Отдельно обрабатываются инициатива, токены, объекты и battle canvas.

## Ограничения и известные проблемы

- Клиент рассчитан на локальный сценарий, а не на публичный продакшен.
- Это не полная замена мастерского VTT-пакета; акцент сделан на боевом экране и управлении сессией.
- Часть UX завязана на текущую структуру state-модели сервера.
